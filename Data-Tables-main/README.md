# Data-Tables

## How to Run 

- To run the Vite Project, install zip file from github repo.
- Extract it.
- Write cmd "npm i" in terminal after opening that unzip folder.
- Enter "npm run dev" to run in "[localhost:5173](http://localhost:5173/)".

## Components

- Pagination Section
- Search Sort Section
- User Form Section
- User Table Section
